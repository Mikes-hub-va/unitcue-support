UnitCue Support

UnitCue helps you compare unit prices and remember prices you have seen while shopping.

Quick help

  • If the scanner misses a field, edit the detected price, quantity, or unit before using it.
  • Compare weight with weight, volume with volume, or compatible count units.
  • If the camera is unavailable, enter values manually.
  • To remove a saved price, swipe it in History and delete it.

Public support

For support, open a GitHub issue. GitHub Issues are public: anyone can read what you post and the replies. Do not include personal information, account details, or other sensitive information.

This site does not currently list a private support channel.
